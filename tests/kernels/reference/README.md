# Reference kernels

Kernels written from well-loved public-domain short stories, for comparing
the pipeline against human craft (docs/reference_stories.md). Each kernel
says what a user would ask for: genre, situation, wishes. It never gives
away the author's solutions. Beside each kernel is the human story's
structure as an outline the 4e judge can read (`*_reference.json`: one
line, its beats as nodes), written for this comparison.

| kernel | story | genre |
|---|---|---|
| ref_canterville | Oscar Wilde, The Canterville Ghost (1887) | comic ghost story |
| ref_speckled_band | Arthur Conan Doyle, The Adventure of the Speckled Band (1892) | fair-play mystery |
| ref_monkeys_paw | W. W. Jacobs, The Monkey's Paw (1902) | horror |
| ref_man_who_would_be_king | Rudyard Kipling, The Man Who Would Be King (1888) | adventure |
| ref_lady_with_the_dog | Anton Chekhov, The Lady with the Dog (1899) | romance |

Not part of the test batch (todo.sh) or the evaluation sets.
